개인정보처리방침

나야나야는 알림을 기기 안에서만 처리합니다. 본 방침은 Google Play 및 관계 법령에 따른 고지입니다.

시행일: 2026년 7월 19일 · 버전 1.2

1. 처리하는 정보

  • 사용자가 허용한 알림 접근으로, 선택한 앱의 알림 제목·본문을 기기에서 읽습니다.
  • 필터용 키워드, 감시 앱·대상 목록, 알람 옵션과 사용자가 선택한 대상 프로필 사진은 기기 내부 저장소에만 보관됩니다.
  • 계정·로그인·클라우드 동기화 기능은 없습니다.

2. 외부 전송

  • 알림 내용·키워드·감시 규칙·대상 프로필 사진을 외부 서버로 전송하지 않습니다.
  • 인터넷은 앱 업데이트 확인·APK 다운로드에만 사용하며, 알림 데이터 수집·분석에는 사용하지 않습니다.
  • 앱 자체는 알림 데이터를 전송하지 않습니다. Google Play를 통한 앱 업데이트는 Play 정책에 따릅니다.
  • 본 앱은 은행 입금 수신·정산 서버 연동과 무관합니다.

3. 이용 목적

중요한 알림을 놓치지 않도록, 선택한 조건에 맞는 알림을 화면 팝업·소리·음성으로 다시 알려 주기 위함입니다.

4. 권한

  • 알림 접근 — 핵심 기능
  • 인터넷 — 앱 업데이트 확인·설치 파일 다운로드만
  • 다른 앱 위에 표시 — 사용 중 팝업 표시
  • 전체 화면 알림 — 잠금 화면 표시 (사이드로드 빌드)
  • 알림·진동 — 재알림 및 표시
  • 정확한 알람 — 재알림 스케줄 (사이드로드 빌드)

5. 보관 및 삭제

설정·최근 알림 목록은 앱 데이터 삭제 또는 앱 제거 시 함께 삭제됩니다. 별도 서버 보관 기간은 없습니다.
